# Definition of Done

A task can be marked as Done only when:

- The related specification exists.
- The scope is implemented.
- Acceptance criteria are met.
- Required tests are created or updated.
- Verification commands pass.
- Documentation is updated.
- No secrets are hard-coded.
- Critical business rules are not duplicated.
- Architecture boundaries are respected.
- Security and authorization are considered.
- Code is ready for review.
