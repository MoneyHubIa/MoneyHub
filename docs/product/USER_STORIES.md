# User Stories

## Authentication

- As a new user, I want to create an account so that I can manage my financial data securely.
- As a user, I want to log in and stay signed in with refresh tokens so that I can use the app without repeated authentication.
- As a user, I want to recover my password so that I can regain access safely.

## Financial Management

- As a user, I want to register income so that I can understand how much money I receive.
- As a user, I want to register expenses so that I can control spending.
- As a business user, I want cost centers so that I can analyze expenses by area.
- As a user, I want accounts payable and receivable so that I can see future obligations and expected cash inflow.

## Planning and Dashboard

- As a user, I want to create financial goals so that I can track progress toward savings or debt targets.
- As a user, I want dashboard KPIs so that I can understand cash flow quickly.
- As a user, I want period comparisons so that I can identify financial changes over time.

## Agenda and Notifications

- As a user, I want financial reminders so that I do not miss bills or commitments.
- As a user, I want recurring events so that repeated obligations are tracked automatically.

## AI

- As a user, I want to ask questions about my finances so that I can understand my data in plain language.
- As a user, I want personalized saving suggestions so that I can improve financial habits.
