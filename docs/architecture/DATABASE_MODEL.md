# Database Model

## Conventions

- Primary keys use UUID.
- Tables include `created_at` and `updated_at`.
- User-owned financial tables include `user_id`, storing the Firebase UID.
- Soft-deletable domain tables include `deleted_at`.
- Monetary values use decimal-compatible database types.
- PostgreSQL runs on Supabase (managed PostgreSQL).

### calendar_events

- `id`
- `user_id`
- `title`
- `scheduled_date`
- `recurrence_rule`
- `recurrence_end_date`
- `notes`
- `reminder_offset_days`
- `created_at`
- `updated_at`

Manual agenda events belong to one user. Dates represent local calendar days;
recurrence accepts `WEEKLY`, `MONTHLY`, or `YEARLY`.

### notifications

- `id`
- `user_id`
- `source`
- `source_id`
- `title`
- `occurrence_date`
- `reminder_date`
- `read_at`
- `created_at`

Notifications belong to one user and use unique
`(user_id, source, source_id, occurrence_date)` keys. They are generated by
explicit idempotent agenda synchronization for events and pending payable or
receivable accounts; no duplicate agenda data is stored for accounts.

### audit_logs
