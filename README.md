# MoneyHub

MoneyHub is a mobile-first financial management SaaS for personal and business users. It combines financial records, planning, dashboards, agenda workflows, and a privacy-aware AI financial assistant.

## Current Stage

The project is in foundation setup. Documentation and task files drive all implementation through Spec Driven Development.
